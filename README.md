# Табло аэропортов

Табло Пулково, Домодедово, Шереметьево и Внуково, плюс крупные хабы мира. Отдельная страница «Сводка топ-10» собирает вылеты по авиакомпаниям, направлениям и аэропортам в разрезе месяцев и недель.

На вкладках — четыре московских и петербургских аэропорта. Шереметьево, Домодедово, Пулково и Внуково читаются с официальных табло, включая дату, терминал и статус. Аэропорты из списка показаны по самолётам, которые сейчас находятся рядом: номер рейса, авиакомпания и город на другом конце маршрута. Европа в списке не показана, кроме Турции. Для хабов это живая картина, а не табло с выходами на весь день.

## Запуск у себя

Нужен Python 3.11 или новее.

```bash
pip install -r requirements.txt
python -m app
```

Откройте http://127.0.0.1:8000

## Ссылка, которую можно отправить

Страница на GitHub — это код. Чтобы у человека сразу открывалось работающее табло, приложение нужно один раз разместить в интернете. После этого ссылка остаётся постоянной.

1. Откройте [кнопку публикации](https://render.com/deploy?repo=https://github.com/ksnyukruz-cmyk/airport-schedule-parser).
2. Войдите через GitHub и подтвердите бесплатный план.
3. Дождитесь адреса вида `https://airport-board.onrender.com`.

Этот адрес и отправляйте. Если страницей какое-то время никто не пользовался, первый заход может занять около половины минуты: бесплатный сервер просыпается.

## Проверки

```bash
python -m unittest discover -s tests
```

Список аэропортов собран из [OurAirports](https://ourairports.com/data/), коды авиакомпаний — из [OpenFlights](https://openflights.org/data.html). Живые рейсы берутся из открытой ленты [adsb.lol](https://adsb.lol/).
