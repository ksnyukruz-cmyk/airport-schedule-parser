# Табло аэропортов

Парсер публичных онлайн-табло с веб-интерфейсом. Сейчас подключены:

| Код | Аэропорт | Что показывает |
| --- | --- | --- |
| SVO | Шереметьево | рейсы на выбранную дату |
| LED | Пулково | рейсы на выбранную дату |
| DME | Домодедово | текущее окно табло вокруг настоящего времени |

Данные читаются с открытых страниц аэропортов. Ключ и регистрация не нужны.

## Запуск

Нужен Python 3.11 или новее.

```bash
pip install -r requirements.txt
python -m app
```

Откройте http://127.0.0.1:8000

На экране можно переключить аэропорт, вылет и прилёт, дату, найти рейс и скачать CSV. Табло само обновляется раз в минуту. Повторный запрос к аэропорту кэшируется на 60 секунд.

Другой порт:

```bash
python -m app --port 8080
```

## API

Список аэропортов:

```bash
curl http://127.0.0.1:8000/api/airports
```

Расписание:

```bash
curl "http://127.0.0.1:8000/api/schedule?airport=SVO&direction=departure&date=2026-10-30"
```

`direction` — `departure` или `arrival`. Параметр `refresh=true` обходит кэш. Описание схемы есть на http://127.0.0.1:8000/docs

## Проверки

```bash
python -m unittest discover -s tests
```

Тесты проверяют разбор ответов и не ходят в интернет.
